# Daily trajectory inspection
Read raw JSONL and local daily CSV using actual archive envelope/schema. Filter by fix date WIB, study MMSI and geographic/SOG bounds; deduplicate by vessel and fix time, exclude conflicting fixes. Split using existing Tracker D0/A plus gap rules. Partial/in-progress segments are not validated trips. No model, receiver or ledger changes. Local-only seven previous days plus today; older Drive archives not fetched automatically. 60-second cache, current-day refresh. MapLibre with filters and points. Tests included; VPS permission and actual-data checks required.
