# Single-release deployment
Use deploy_integrated.sh FULL_COMMIT --check for nonmutating preflight; --apply runs the identical gates then replaces the complete app directory. The pinned manifest verifies Git blob hashes before and after install. No test files in runtime. AIS receiver source update is refused unless its original blob matches the reviewed base (or candidate). Raw AIS, credentials, model release, history seed, MediaMTX config and AIS archive timer stay in place. Receiver restart only for provenance patch. Previous app retained once, and rollback preserves operational state, with newly added audit columns saved before compatibility conversion. No automatic removal of shared legacy root or old model envs. Check VPS unit dependencies before further removal. Vehicle archive retention uses verified files; SQL deletion is limited to a later reconciled opening checkpoint. Structural replay and component parity do not establish scientific field accuracy. Historical incomplete records remain incomplete unless actual evidence is sufficient; no prediction backfill.
