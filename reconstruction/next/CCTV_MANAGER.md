# CCTV Connection Manager
Based on ETA–ETD f01b1ba and CCTV-to-YOLO bc742b0. Fixed paths Bengkalis/Pakning, publisher credentials editable, separate administrator bearer token, no public Control API. Uses persistent JSON (YAML-compatible) config in /var/lib/bima2-cctv with atomic replacement and checks MediaMTX hot reload. Original config remains unchanged for rollback. Existing reader credentials retained. Passwords never returned by BIMA2 API or committed. Device metadata and timestamp stored separately. Status shows readiness, codec tracks, bytes and reader count; bitrate and YOLO heartbeat not yet implemented. Camera encoder settings remain on camera. Changes disconnect previous RTMP publisher if present. Test actual MediaMTX hot reload and credential replacement before field operation. No stock ledger reset or changes to AIS. Installer requires system PyYAML. Initial install restarts relay and BIMA2. Plain RTMP/RTSP unencrypted. No remote shell access available; runtime testing pending.
